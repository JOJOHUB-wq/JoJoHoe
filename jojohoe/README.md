# JoJoHoe - Плагин на Кастомные Мотыги 🌾

Добро пожаловать в документацию по плагину JoJoHoe! Этот плагин добавляет на ваш сервер особые мотыги с системой прокачки, кастомной удачей и гибкими настройками.

## 🌟 Основные Возможности

- **Система Уровней**: Прокачивайте мотыгу, ломая урожай! С каждым новым уровнем мотыга становится лучше: меняется её материал, добавляются новые зачарования.
- **Гибкая Настройка**: Все уровни, сообщения, и даже рецепт крафта настраиваются в файле `config.yml`.
- **Кастомная Удача**: В дополнение к ванильной удаче, у мотыги есть свой параметр `fortune_bonus`, который даёт дополнительный урожай.
- **Интеграция с WorldGuard**: Управляйте, в каких регионах игроки могут использовать мотыгу, с помощью кастомного флага `jojo-hoe-use`.
- **Поддержка Русский Языка**: Все сообщения для игроков уже на русском языке.

## コマンド (Команды)

Основная команда плагина - `/hoe`.

- `/hoe reload` - Перезагружает конфигурацию плагина.
- `/hoe [id_уровня]` - Выдаёт вам особую мотыгу указанного уровня.
- `/hoe <игрок> [id_уровня]` - Выдаёт другому игроку особую мотыгу.

## 🔑 Права (Permissions)

- `jojohoe.use` - **(Выдаётся всем по умолчанию)** Позволяет игрокам прокачивать мотыгу. Без этого права прогресс не засчитывается.
- `jojohoe.give.self` - **(OP)** Позволяет выдавать мотыгу себе.
- `jojohoe.give.others` - **(OP)** Позволяет выдавать мотыгу другим игрокам.
- `jojohoe.reload` - **(OP)** Позволяет перезагружать конфигурацию.

## 🛡️ Интеграция с WorldGuard

Плагин добавляет кастомный флаг для WorldGuard, который позволяет контролировать использование мотыг в регионах.

- `/rg flag <название_региона> jojo-hoe-use allow` - ✅ **Разрешает** игрокам прокачивать мотыгу в этом регионе.
- `/rg flag <назва_регіону> jojo-hoe-use deny` - ❌ **Запрещает** игрокам прокачивать мотыгу в этом регионе.

Если флаг не установлен, мотыгу использовать можно (поведение по умолчанию).

## 🔧 Настройка `config.yml`

Файл `config.yml` - это сердце плагина. В нём вы можете:
- Изменить названия, материалы, необходимые очки опыта и зачарования для каждого уровня мотыги.
- Настроить параметр `fortune_bonus` для кастомной удачи.
- Включить или выключить рецепт крафта и изменить его.
- Перевести или изменить любые сообщения, которые видят игроки.
